# Sparse-View 3D Gaussian Avatar Reconstruction

用 **3 个训练视角** 重建可自由视角渲染的人体化身。在同一框架、同一数据、同一评测口径下，
相对 vanilla 3DGS 达到 **PSNR +15.3% / SSIM +33.9% / LPIPS −35.3%**。

> 代码与数据集受第三方协议约束，不在本仓库公开。这里记录方法设计、消融结论与评测协议。

---

## 1. 问题：视角降到 3 个，3DGS 会怎么坏

3DGS 在几十张视角下重建质量很好，但训练视角掉到 3 个时，几何约束严重不足，出现三类可观察的失败：

| 现象 | 表现 | 根因 |
|---|---|---|
| **floater 增生** | 人体周围漂浮大量半透明高斯 | 未见区域缺少监督，密度控制把噪声点当细节保留 |
| **表面撕裂** | 手臂、衣摆等处出现空洞 | 高斯分布发散，没有被约束到真实表面上 |
| **时序抖动** | 相邻帧同一部位位置跳变 | 每帧独立优化，帧间没有一致性约束 |

这三类问题指向同一个缺口：**缺少一个"人体表面在哪"的先验**。

---

## 2. 方法：两条互补的正则

### 2.1 SAS — Surface-Anchored Smoothing

用 SMPL 网格顶点构建表面锚定先验，把高斯往有效的人体表面上拉：

```
对每个高斯 g：
  找最近的 SMPL 表面点 p_surf
  约束 g 的中心到 p_surf 的距离、以及 g 的尺度沿法向的分量
```

设计目标是**几何与时序一致性**，不是直接冲 PSNR——这一点在后面的消融里得到了验证。

### 2.2 时序正则

引入 `lambda_temporal`，在相邻帧之间约束高斯属性（位置、尺度、不透明度）的变化幅度，
抑制抖动。这是本方案相对单帧独立优化的主要差异来源。

---

## 3. ★ 一个 1000 倍的单位 bug，把结论从"证伪"翻转成"成立"

这是整个项目里最有价值的一段，也是我认为最值得写下来的部分。

### 3.1 现象：SAS 一开始是负收益

第一版消融结果里，开 SAS 反而比关掉更差：

| 配置 | PSNR |
|---|---|
| SAS 关 | 13.794 |
| SAS 开 | 13.310 |
| **Δ** | **−0.484 dB** |

按常规做法，这时候的结论应该是"这个模块没用，砍掉"。但 −0.48 dB 的降幅不像"没用"，
更像是**某种结构性破坏**——模块没效果通常是持平，明显变差说明它把什么东西搞坏了。

### 3.2 根因：SMPL 单位差了 1000 倍

逐层排查后定位到：SMPL 输出的顶点是**米**，而场景坐标系是**毫米**，两者差 1000 倍。

于是所有 SMPL 顶点在场景坐标系里**塌缩成一个点**。锚面退化成一个点之后，SAS 做的事情变成
"把所有高斯拉向同一个点"——几何被直接摧毁。这解释了为什么是"明显变差"而不是"没效果"。

### 3.3 修复后：+0.884 dB，三项指标全正

| 实验 | PSNR | SSIM | LPIPS↓ |
|---|---|---|---|
| `k3_full`（SAS 开） | **14.194** | **0.5139** | **0.1451** |
| `k3_no_sas`（SAS 关） | 13.310 | 0.4918 | 0.1536 |
| **Δ（SAS 净贡献）** | **+0.884 dB** | **+4.49%** | **−5.53%** |

### 3.4 附加证据：λ 的单调剂量反应

如果增益来自正则机制本身，那么调大权重应该单调变好，直到过正则。实测：

| λ | PSNR |
|---|---|
| 0（关） | 13.310 |
| 0.02 | 13.118 |
| 0.05 | 14.042 |
| **0.10（默认）** | **14.194** |

单调递增到默认值。这条曲线比单点对比更能说明"增益来自机制"而不是"碰巧调对了参数"。

### 3.5 这一段的结论

> **这不是调参，是"先验被正确注入"与"被错误注入"的差别。**

一个模块被判定为负收益时，"砍掉"是最省事的选择，但也是**最可能埋掉正确想法**的选择。
先区分"机制无效"和"机制被错误注入"，再决定取舍。

同一批实验里，另外两个改法也确实被证伪了，这一类才是真该砍的：

| 变体 | ΔPSNR | 结论 |
|---|---|---|
| 单向 SAS | +0.09 dB | 持平，无增量 |
| 法向单向 SAS | −0.58 dB | 负收益 |
| 薄壳各向异性初始化 | −1.08 dB | 证伪 |

## 4. 主结果（K=3，受控对比）

**口径**：MVHumanNet `202219` 序列，K=3 训练视角，21 个 novel view × 8 帧，
指标在**前景掩膜内**计算，LPIPS 越低越好。

| 方法 | PSNR↑ | SSIM↑ | LPIPS↓ | ΔPSNR | ΔSSIM |
|---|---|---|---|---|---|
| vanilla 3DGS | 12.312 | 0.3839 | 0.2241 | — | — |
| **本方案（SAS + 时序正则）** | **14.194** | **0.5139** | **0.1451** | **+15.3%** | **+33.9%** |

---

## 5. 评测协议：为什么强调"受控对比"

稀疏视角人体重建这个方向上，论文之间的数字**普遍不可直接比较**：训练视角数不同、
novel view 采样不同、是否在掩膜内计算不同、LPIPS 版本不同，都能让 PSNR 差出 1~2 dB。

所以这里做的是**系统级工作**，而不是只报自己的数字：

1. **统一框架**：复现 6 个代表性方法（GPS-Gaussian / AnimatableGaussians /
   SplattingAvatar / HUGS / 3DGS-Avatar / ENeRF），全部跑到 3 视角；
2. **统一划分**：同一组训练视角、同一组 novel view、同一批帧；
3. **统一口径**：独立 `evaluate.py`，掩膜内计算，指标方向统一为"越高越好"；
4. **量化噪声底**：同一 config 跨 batch 重跑，测出方差上界，避免把 0.2 dB 的
   批次波动当成方法差异。

## 6. 工程侧的几个坑（记录备查）

| 坑 | 表现 | 处理 |
|---|---|---|
| `use_smpl_init=True` 静默覆盖 `use_mask_init` | 初始化策略被悄悄换掉，结果不可比 | 显式断言互斥，启动时打印最终生效的初始化方式 |
| 训练内联评测 vs 独立 evaluate | 存在恒定 ~0.35 dB 系统偏差 | 两套都保留，交付统一用独立评测 |
| 小 bbox 下 LPIPS 崩溃 | 掩膜极小时裁剪区域退化 | bbox 加最小尺寸保护 |
| 批次效应 | 同 config 跨批次差 0.19~0.29 dB | 所有对比强制同批次 |
